# สรุปงาน: เข้าสู่ระบบ

**รอบที่:** 1 · **อัปเดต:** 2026-10-24 · **สถานะ:** กำลังออกแบบ

**เปิดดูได้ที่:** `/draft/login`  (เปิดเว็บแล้วกดปุ่ม "Go to Drafts" หรือพิมพ์ที่อยู่นี้ต่อท้ายเว็บ)

## 1. สิ่งที่ทำเสร็จแล้ว
- นี่คือ **ฉบับคัดลอกของหน้าจริงที่ใช้งานอยู่ตอนนี้** เพื่อให้ทีมออกแบบเริ่มแก้ไขจากหน้าเดียวกับที่ผู้ใช้เห็น ยังไม่มีการเปลี่ยนแปลงดีไซน์
- ฝั่งซ้ายเป็นการ์ดกระดาษ "จดหมายเชิญกลับหมู่บ้าน" มีช่องชื่อผู้ใช้หรืออีเมล ช่องรหัสผ่าน (กดดู/ซ่อนได้) ช่องติ๊ก "จดจำฉัน" ลิงก์ "ลืมรหัสผ่าน?" และปุ่ม "เข้าสู่ระบบ"
- ด้านล่างการ์ดมีลิงก์ "สร้างบัญชีใหม่"
- ฝั่งขวา (เฉพาะจอกว้าง) เป็นภาพจดหมายตกแต่ง

## 2. สิ่งที่กดหรือลองได้
- กดปุ่ม "เข้าสู่ระบบ" ในร่างจะแสดงตัวอย่างข้อความผิดพลาด (ยังไม่ได้เข้าสู่ระบบจริง)
- แผง **"Preview state (draft only)"** มุมซ้ายล่าง ใช้สลับดู: ปกติ / กำลังเข้าสู่ระบบ / รหัสผ่านไม่ถูกต้อง / ยังไม่ยืนยันอีเมล / ข้อผิดพลาดทั่วไป แผงนี้มีเฉพาะในร่าง
- "ลืมรหัสผ่าน?" พาไปหน้าลืมรหัสผ่าน, "สร้างบัญชีใหม่" พาไปหน้าสมัครสมาชิก

## 2b. เปลี่ยนจากรอบก่อน (เฉพาะรอบแก้ไข)
- ยังไม่มีรอบแก้ไข
- หน้านี้ขึ้นเว็บจริงแล้ว: หน้าจริงจะยังไม่เปลี่ยนจนกว่า dev จะนำการแก้ไขนี้ไปใช้

## 3. ใช้ของเดิม และของใหม่
**ใช้ของเดิมที่มีอยู่แล้ว (ไม่ต้องทำใหม่):**
- กรอบหน้ากระดาษ การ์ดกระดาษ ตราประทับ เส้นคั่นหมึก
- ช่องกรอกข้อความ ช่องรหัสผ่านแบบกดดู/ซ่อนได้ ช่องติ๊ก และปุ่มหลัก
- ภาพจดหมายตกแต่งฝั่งขวา

**ของใหม่ที่ต้องสร้างเพิ่ม** (dev จะต้องใช้เวลามากขึ้น):
- ไม่มี (แผงสลับสถานะเป็นของสำหรับร่างเท่านั้น)

## 4. สิ่งที่เดาไว้ — รบกวนช่วยยืนยัน
- ข้อความทั้งหมดคัดลอกจากหน้าจริง ไม่ได้เดาเพิ่ม
- ข้อความผิดพลาด "Invalid credentials" ในแผงสลับสถานะเป็นตัวอย่าง ของจริงจะเป็นข้อความจากระบบหลังบ้าน

## 5. สิ่งที่ยังไม่ใช่ของจริง
- ข้อมูลในหน้านี้เป็นข้อมูลตัวอย่าง ยังไม่เชื่อมระบบหลังบ้าน
- ข้อความเป็นภาษาไทยอย่างเดียว ยังไม่มีภาษาอังกฤษ
- ช่อง "จดจำฉัน" ยังไม่ทำอะไรจริง ๆ ในร่างนี้

## 6. คำถามสำหรับรอบถัดไป

# สรุปงาน: เข้าสู่ระบบ

**รอบที่:** 2 · **อัปเดต:** 2026-11-02 · **สถานะ:** กำลังออกแบบ

**เปิดดูได้ที่:** `/draft/login`  (เปิดเว็บแล้วกดปุ่ม "Go to Drafts" หรือพิมพ์ที่อยู่นี้ต่อท้ายเว็บ)

## 1. สิ่งที่ทำเสร็จแล้ว
- ปรับหน้าให้เหลือการ์ดกระดาษใบเดียวอยู่กึ่งกลาง ตามรูปที่แนบ
- หัวข้อ "ยินดีต้อนรับกลับ" อยู่ในการ์ด เอาหัวหน้าแยก ตราประทับ และภาพจดหมายด้านข้างออก
- ช่องชื่อผู้ใช้หรืออีเมล ช่องรหัสผ่าน "จดจำฉัน" "ลืมรหัสผ่าน?" ปุ่มเข้าสู่ระบบ และลิงก์สร้างบัญชีใหม่ยังอยู่ครบ

## 2. สิ่งที่กดหรือลองได้
- กรอกข้อมูล กดดู/ซ่อนรหัสผ่าน และติ๊ก "จดจำฉัน" ได้
- กด "เข้าสู่ระบบ" ในร่างเพื่อดูตัวอย่างข้อผิดพลาด หรือใช้แผง "Preview state (draft only)" ใต้การ์ดเพื่อดูสถานะต่าง ๆ
- "ลืมรหัสผ่าน?" ไปหน้าลืมรหัสผ่าน และ "สร้างบัญชีใหม่" ไปหน้าสมัครสมาชิก

## 2b. เปลี่ยนจากรอบก่อน
- เปลี่ยนจากเค้าโครงสองคอลัมน์เป็นการ์ดใบเดียวกึ่งกลางหน้าจอ
- เอาหัวหน้าแยก ตราประทับ และภาพประกอบด้านข้างออก
- ย้ายแผงสลับสถานะจากมุมจอมาไว้ใต้การ์ดเพื่อไม่ให้บังเนื้อหาบนจอเล็ก
- หน้าเว็บจริงจะยังไม่เปลี่ยนจนกว่า dev จะนำการแก้ไขนี้ไปใช้

## 3. ใช้ของเดิม และของใหม่
**ใช้ของเดิมที่มีอยู่แล้ว:**
- พื้นหลังและการ์ดกระดาษ เส้นคั่น ช่องกรอก ช่องรหัสผ่านแบบดู/ซ่อนได้ ช่องติ๊ก และปุ่มหลักสีน้ำตาลเข้ม

**ของใหม่ที่ต้องสร้างเพิ่ม:**
- ไม่มี หน้านี้ปรับการจัดวางจากส่วนที่มีอยู่แล้ว ส่วนเอฟเฟ็คม้วนกระดาษอยู่ในป๊อปอัพของหน้าแรก

## 4. สิ่งที่เดาไว้ — รบกวนช่วยยืนยัน
- ไม่มี ผู้ออกแบบยืนยันหน้าตาตามรูปและการคงการทำงานเดิมแล้ว

## 5. สิ่งที่ยังไม่ใช่ของจริง
- ฟอร์มยังไม่เชื่อมระบบเข้าสู่ระบบจริง ข้อความผิดพลาด "Invalid credentials" เป็นตัวอย่าง
- ช่อง "จดจำฉัน" ยังไม่ส่งข้อมูลจริง ข้อความเป็นภาษาไทยอย่างเดียว และแผงสลับสถานะมีไว้สำหรับร่างเท่านั้น

## 6. คำถามสำหรับรอบถัดไป
- ไม่มีคำถามค้าง

# สรุปงาน: ลืมรหัสผ่าน

**รอบที่:** 1 · **อัปเดต:** 2026-10-24 · **สถานะ:** กำลังออกแบบ

**เปิดดูได้ที่:** `/draft/forgot-password`  (เปิดเว็บแล้วกดปุ่ม "Go to Drafts" หรือพิมพ์ที่อยู่นี้ต่อท้ายเว็บ)

## 1. สิ่งที่ทำเสร็จแล้ว
- นี่คือ **ฉบับคัดลอกของหน้าจริงที่ใช้งานอยู่ตอนนี้** เพื่อให้ทีมออกแบบเริ่มแก้ไขจากหน้าเดียวกับที่ผู้ใช้เห็น ยังไม่มีการเปลี่ยนแปลงดีไซน์
- หน้านี้เป็นการ์ดกระดาษกลางจอ มีตราประทับรูป "?" หัวข้อ "รีเซ็ตรหัสผ่าน" คำอธิบายสั้น ๆ ช่องกรอกอีเมล และปุ่ม "ส่งลิงก์รีเซ็ต"
- ด้านล่างมีลิงก์ "กลับไปเข้าสู่ระบบ"

## 2. สิ่งที่กดหรือลองได้
- พิมพ์อีเมลแล้วกด "ส่งลิงก์รีเซ็ต" จะเห็นการ์ดสำเร็จ "ตรวจสอบกล่องจดหมาย" (ยังไม่ได้ส่งอีเมลจริง)
- มีแผง **"Preview state (draft only)"** มุมซ้ายล่าง ใช้สลับดูหน้าตาแต่ละสถานะ: ปกติ / กำลังส่ง / เกิดข้อผิดพลาด / ส่งสำเร็จ แผงนี้มีเฉพาะในร่าง ไม่ขึ้นเว็บจริง
- ลิงก์ "กลับไปเข้าสู่ระบบ" และปุ่มย้อนกลับด้านบนพาไปหน้าเข้าสู่ระบบ

## 2b. เปลี่ยนจากรอบก่อน (เฉพาะรอบแก้ไข)
- ยังไม่มีรอบแก้ไข
- หน้านี้ขึ้นเว็บจริงแล้ว: หน้าจริงจะยังไม่เปลี่ยนจนกว่า dev จะนำการแก้ไขนี้ไปใช้

## 3. ใช้ของเดิม และของใหม่
**ใช้ของเดิมที่มีอยู่แล้ว (ไม่ต้องทำใหม่):**
- กรอบหน้ากระดาษพร้อมหัวข้อและปุ่มย้อนกลับ
- การ์ดกระดาษ ตราประทับ เส้นคั่นหมึก
- ช่องกรอกข้อความ ปุ่มหลัก และปุ่มกรอบเส้น

**ของใหม่ที่ต้องสร้างเพิ่ม** (dev จะต้องใช้เวลามากขึ้น):
- ไม่มี (แผงสลับสถานะเป็นของสำหรับร่างเท่านั้น)

## 4. สิ่งที่เดาไว้ — รบกวนช่วยยืนยัน
- ข้อความทั้งหมดคัดลอกจากหน้าจริง ไม่ได้เดาเพิ่ม
- ข้อความ "เกิดข้อผิดพลาด" ในแผงสลับสถานะเป็นตัวอย่างเท่านั้น ของจริงจะเป็นข้อความที่ระบบหลังบ้านส่งมา

## 5. สิ่งที่ยังไม่ใช่ของจริง
- ข้อมูลในหน้านี้เป็นข้อมูลตัวอย่าง ยังไม่เชื่อมระบบหลังบ้าน
- ข้อความเป็นภาษาไทยอย่างเดียว ยังไม่มีภาษาอังกฤษ

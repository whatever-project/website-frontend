# สรุปงาน: รีเซ็ตรหัสผ่าน

**รอบที่:** 1 · **อัปเดต:** 2026-10-24 · **สถานะ:** กำลังออกแบบ

**เปิดดูได้ที่:** `/draft/reset-password`  (เปิดเว็บแล้วกดปุ่ม "Go to Drafts" หรือพิมพ์ที่อยู่นี้ต่อท้ายเว็บ)

## 1. สิ่งที่ทำเสร็จแล้ว
- นี่คือ **ฉบับคัดลอกของหน้าจริงที่ใช้งานอยู่ตอนนี้** เพื่อให้ทีมออกแบบเริ่มแก้ไขจากหน้าเดียวกับที่ผู้ใช้เห็น ยังไม่มีการเปลี่ยนแปลงดีไซน์
- ผู้ใช้เปิดหน้านี้จากลิงก์ในอีเมลที่ได้รับหลังกด "ลืมรหัสผ่าน"
- การ์ดกระดาษกลางจอ มีตราประทับรูปกุญแจ หัวข้อ "ตั้งรหัสผ่านใหม่" คำแนะนำว่าต้องมีอย่างน้อย 8 ตัวอักษร ช่องรหัสผ่านใหม่ (กดดู/ซ่อนได้) และปุ่ม "รีเซ็ตรหัสผ่าน"

## 2. สิ่งที่กดหรือลองได้
- พิมพ์รหัสผ่านอย่างน้อย 8 ตัวแล้วกดปุ่ม จะเห็นการ์ดสำเร็จ (ยังไม่ได้เปลี่ยนรหัสผ่านจริง และในร่างนี้ยังไม่พากลับไปหน้าเข้าสู่ระบบอัตโนมัติ แต่หน้าจริงจะพาไปหลังประมาณ 2.5 วินาที)
- แผง **"Preview state (draft only)"** มุมซ้ายล่าง ใช้สลับดู: ฟอร์ม / กำลังรีเซ็ต / เกิดข้อผิดพลาด / สำเร็จ / ลิงก์ไม่ถูกต้อง แผงนี้มีเฉพาะในร่าง
- ในสถานะ "ลิงก์ไม่ถูกต้อง" ปุ่ม "ขอลิงก์ใหม่" พาไปหน้าลืมรหัสผ่าน

## 2b. เปลี่ยนจากรอบก่อน (เฉพาะรอบแก้ไข)
- ยังไม่มีรอบแก้ไข
- หน้านี้ขึ้นเว็บจริงแล้ว: หน้าจริงจะยังไม่เปลี่ยนจนกว่า dev จะนำการแก้ไขนี้ไปใช้

## 3. ใช้ของเดิม และของใหม่
**ใช้ของเดิมที่มีอยู่แล้ว (ไม่ต้องทำใหม่):**
- กรอบหน้ากระดาษ การ์ดกระดาษ ตราประทับ เส้นคั่นหมึก
- ช่องรหัสผ่านแบบกดดู/ซ่อนได้ ปุ่มหลัก และปุ่มกรอบเส้น

**ของใหม่ที่ต้องสร้างเพิ่ม** (dev จะต้องใช้เวลามากขึ้น):
- ไม่มี (แผงสลับสถานะเป็นของสำหรับร่างเท่านั้น)

## 4. สิ่งที่เดาไว้ — รบกวนช่วยยืนยัน
- ข้อความทั้งหมดคัดลอกจากหน้าจริง ไม่ได้เดาเพิ่ม
- ข้อความ "เกิดข้อผิดพลาด" ในแผงสลับสถานะเป็นตัวอย่าง ของจริงจะเป็นข้อความจากระบบหลังบ้าน

## 5. สิ่งที่ยังไม่ใช่ของจริง
- ข้อมูลในหน้านี้เป็นข้อมูลตัวอย่าง ยังไม่เชื่อมระบบหลังบ้าน
- ข้อความเป็นภาษาไทยอย่างเดียว ยังไม่มีภาษาอังกฤษ

## 6. คำถามสำหรับรอบถัดไป
- ทีมออกแบบอยากเปลี่ยนอะไรในหน้านี้บ้าง? (เช่น อยากให้แสดงเงื่อนไขความแข็งแรงของรหัสผ่านเหมือนหน้าสมัครสมาชิกหรือไม่)
